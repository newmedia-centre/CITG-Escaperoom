# CITG Escaperoom

An online escape room game designed for the Civil Engineering faculty. This interactive web-based game challenges students with a series of engineering-themed puzzles and problems, which are solved using formulas and lessons from their coursework. Students progress through levels, earn scores based on their performance, and compete on a public leaderboard.

## Project Overview

CITG Escaperoom is an engaging educational tool aimed at reinforcing Civil Engineering concepts through gamification. The game consists of multiple levels, each featuring unique puzzles that require critical thinking and knowledge application. As students solve puzzles, they accumulate points, and their scores are displayed on a leaderboard to foster a sense of competition and achievement.

## Features

- Multiple escape room levels with Civil Engineering puzzles
- Real-time scoring based on accuracy and speed
- Public leaderboard for top performers
- Web-based interface accessible from any modern browser
- Designed specifically for Civil Engineering students

## Setup Instructions

### Prerequisites

- [Node.js](https://nodejs.org/) (version 14 or higher recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

1. Clone this repository:
   ```bash
   git clone [https://github.com/<your-org-or-username>/CITG-Escaperoom.git](https://github.com/<your-org-or-username>/CITG-Escaperoom.git)
   cd CITG-Escaperoom

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

The application will be available at http://localhost:3000 (or another port if specified).

## How to Play

1. Open the game in your browser.
2. Register or log in with your student credentials (if required).
3. Select a level to begin solving puzzles.
4. Use your Civil Engineering knowledge to solve each puzzle. Enter your answers and submit.
5. Earn points for correct answers and quick completion.
6. Progress through additional levels as you solve puzzles.
7. Check your ranking on the leaderboard and compete with fellow students!

## Leaderboard and Scoring

Scores are calculated based on puzzle accuracy and completion time.
The leaderboard displays the top-performing students.
